About this Contest
A technical contest for building intelligent, workflow-driven AI agents — designed to get better with use and to research dynamically based on the task or purpose at hand.

Problem Statement
Design and build an AI Agentic System that leverages a Large Language Model (LLM) to autonomously perform a basic task through a well-defined, structured workflow.

The system should demonstrate the core principles of agentic behaviour — reasoning, planning, tool use, and execution — rather than simply calling an LLM for a one-shot response.

Core Requirements

Your agent must:

Accept a task/goal from the user (text-based input).
Break down the task into a sequence of logical steps (planning).
Use the LLM to reason about each step and decide the next action.
Execute actions — this could involve calling tools/APIs, performing calculations, searching data, reading/writing files, etc.
Maintain state/context across steps of the workflow.
Return a final, coherent output that fulfills the original task.
Example Task Ideas (Choose One or Propose Your Own)

Research Agent: Given a topic, search, summarize, and compile a short report.
Competitive Intelligence Agent: Tracks competitor pricing, positioning, hiring platform launches, and feature releases on a recurring basis.
Market Research Agent: Surveys/interviews synthesis, TAM/SAM/SOM estimation, industry benchmarking.
Lead Finder Agent: Builds prospect lists from an ideal-customer profile (e.g., colleges, hiring managers, engineering firms) using web/LinkedIn/Apollo-style data.
Lead Enrichment Agent: Takes raw leads (name/company/email) and fills in firmographics, contact info, and buying signals.
Lead Scoring Agent: Ranks leads by fit and intent signals so outreach prioritizes the best prospects first.
Scheduler/Task Planner Agent: Turns a goal into a sub-task plan and can trigger scheduled runs (weekly outreach, recurring reports).
Employee Performance Tracking Agent: Daily activity logs, product suggestions, performance summaries (matches a need you've flagged before).
Task Planner Agent: Given a goal (e.g., "plan a 3-day trip"), break it into sub-tasks and generate a structured plan.
Data Assistant Agent: Given a CSV/dataset, analyze it and answer natural language questions about it.
Code Helper Agent: Given a coding problem, plan the approach, write code, test it, and fix errors iteratively.
Customer Support Agent: Simulate handling a support query using a knowledge base + escalation logic.
Participants are free to choose any basic task, as long as it clearly demonstrates agentic workflow behaviour (plan → act → observe → respond), not just a single LLM prompt-response.

Objective

The goal of this contest is to evaluate participants' understanding of:

LLM-based reasoning and prompting techniques
Agentic design patterns (ReAct, Plan-and-Execute, Tool-use, etc.)
Workflow orchestration (sequential/conditional steps)
Practical integration of LLMs with external tools or data
Contest Guidelines

Technology Stack

Any programming language is allowed (Python is recommended).
Any LLM provider/API may be used (OpenAI, Anthropic Claude, open-source models like LLaMA, Mistral, etc.).
Agent frameworks are optional but allowed (LangChain, LangGraph, AutoGen, CrewAI, or custom implementation).

Rules

Plagiarism or copying existing open-source agent projects without modification is strictly prohibited.
Use of AI coding assistants (e.g., Copilot, Claude, ChatGPT) for coding help is allowed, but the core logic and design must be your own.
Teams must not use any paid/restricted API without disclosing usage; free-tier or open-source models are encouraged for fairness.
All submissions must be original and created during the contest window.
Any form of malpractice will lead to immediate disqualification.
